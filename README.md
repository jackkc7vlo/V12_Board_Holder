# V12 Board Holder

Board Holder for V12 of the T41-EP SDT software defined transceiver.

The print was created in FreeCad and is a parametric design.

To obtain the latest files, they can be retrieved from github by using the following command:

git clone https://github.com/jackkc7vlo/V12_Board_Holder.git

Making adjustments are done by opening the V12_Board_Holder.FCStd file in FreeCad version 1.01 or higher, then then adjusting the measurements in the spreadsheet. For example, if you want to adjust the spacing between the boards, just change the base_width parameter.  It’s presently adjusted so the holes line up with the 3d printed case found on the T41-EP Groups.IO site. 

https://groups.io/g/SoftwareControlledHamRadio/files

You then just need to export it as a .stl file.
